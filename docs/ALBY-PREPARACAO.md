Código fonte, não prova de API real. A documentação do próprio provedor marca esta *Alby Wallet API* como **deprecated**, e disponibilidade/compatibilidade atual não foi validada.

Segundo a documentação do Alby (https://guides.getalby.com/developer-guide/developer-guide/alby-wallet-api/reference/authorization), escopos de leitura: `balance:read` para `/balance`, `invoices:read` para consulta de entrada. `invoices:create` permite `POST /invoices` e **não** deve ser concedido nesta fase de leitura. **Nunca conceder `payments:send`, `transactions:read` ou `account:read` sem justificativa específica.** Se a UI de tokens não permitir separar esses escopos ou a API legada não aceitar o token restrito, **parar**. Mesmo `invoices:create` gera fatura potencialmente pagável e requer aprovação nova antes de uso. Evitar uma conta Alby de produção ou com saldo; o usuário pediu apenas preparação.
